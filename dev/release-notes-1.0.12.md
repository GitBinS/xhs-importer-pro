把小红书笔记导入 Obsidian 知识库：正文、全部图片、话题标签、作者信息与互动数据，落成本地 Markdown。

## 功能概览

- **从分享链接导入** —— 支持 `xhslink.com`/`xhslink.cn` 短链、App 与网页分享链接
- **批量导入** —— 一次粘贴多条链接，单次上限 20 条，请求间随机节流 1.5–3.5 秒
- **按笔记 ID 去重** —— 删掉笔记后可重新导入
- **图片全部下载到本地** —— 同名图片已存在时直接复用
- **互动数据** —— 点赞 / 收藏 / 评论 / 分享数写入 frontmatter
- **发布时间与作者** —— 含真实发布时间、作者昵称 / ID / 主页链接
- **落点与 frontmatter 可配**、**界面中英双语**

完整功能、可用占位符、安装步骤与配置示例见 [README](https://github.com/GitBinS/xhs-importer-pro#readme)。

## 本版变更（1.0.12）

**移除作者主页抓取功能**，以及配套的「补抓作者的缺失信息」命令。

作者的**小红书号**只在作者主页下发，而该接口限流严格 —— 连发请求会被重定向到登录页，批量导入时多数笔记拿不到，加节流与重试后仍不稳定，故移除。`{{authorRedId}}`、`{{authorDesc}}`、`{{authorFans}}`、`{{authorIpLocation}}` 四个占位符一并删除。

保留 `{{authorUrl}}` —— 由作者 ID 直接拼出，**不需要额外请求**，点开即可在主页看到小红书号。
