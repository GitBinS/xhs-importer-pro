# dev/ —— 开发辅助脚本

这些脚本**不是插件运行时的一部分**（Obsidian 只加载根目录的 `main.js` / `manifest.json` / `styles.css`）。
它们只是开发与排障时用的工具，方便换机器后仍能复用。

---

## verify.mjs —— 逻辑回归测试

```bash
cd xhs-importer-pro
node dev/verify.mjs
```

- 拦掉 `require('obsidian')` 后**直接加载 `../main.js`**，跑纯函数测试
- **改完 `main.js` 后应该跑一遍**（当前 9 项：URL 提取与规范化 / 正文行清理 / 文件名 emoji 保留 / 发布时间格式化 / 互动数归一化）
- 路径从本文件相对解析，**换机器不用改**

> ⚠️ 末尾有一段「端到端」测试：真去抓一篇小红书笔记并渲染 frontmatter。
> 它需要**网络 + 一个未过期的分享链接** —— 分享链接里的 `xsec_token` 会过期，
> 所以这段**经常失败，属正常现象**，不影响上面单测的结论。
> 想跑通它，把脚本里的测试链接换成刚复制的分享链接。

## probe.mjs —— 页面字段探测

```bash
node dev/probe.mjs <分享链接> [更多链接...]
```

抓笔记页并打印 `__INITIAL_STATE__` 里的**全部字段**，用来确认无登录状态下到底能拿到什么。

**当前实测结论**：

| 拿得到 | 拿不到 |
|---|---|
| 标题 / 正文 / 图片（可下载）/ 视频直链 / 发布时间 / IP 属地 / 作者昵称与 userId / 点赞·收藏·评论·分享数 / 话题标签 | **评论区内容**（需登录） |

⚠️ **必须用「分享链接」** —— App 里「分享 → 复制链接」，或网页版的分享按钮。
浏览器地址栏复制的 `explore/<id>?xsec_token=...` 里，token **绑定登录会话**，裸请求必被拦（302 → 登录页）。
