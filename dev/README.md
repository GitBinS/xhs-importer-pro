# dev/ —— 开发辅助脚本

这些脚本**不是插件运行时的一部分**（Obsidian 只加载根目录的 `main.js` / `manifest.json` / `styles.css`）。
它们只是开发与排障时用的工具，方便换机器后仍能复用。

---

## verify.mjs —— 逻辑回归测试

```bash
cd xhs-importer-pro
node dev/verify.mjs
```

- **全程离线**，不联网、不需要分享链接、不受 token 过期影响
- 拦掉 `require('obsidian')` 后**直接加载 `../main.js`**，调用**真实插件方法**（不是手抄的逻辑副本）
- 路径从本文件相对解析，**换机器不用改**；失败时返回**非零退出码**

**改完 `main.js` 后应该跑一遍。当前 43 项断言，覆盖 6 组：**

| # | 组 | 覆盖内容 |
|---|---|---|
| 1 | `formatPublishDate` | 时间戳→日期、空值/垃圾值；**时区回归**（本地构造 00:43，退回 UTC 实现即失败） |
| 2 | `normalizeCount` | 字符串数字、真实零保留；**缺失必须渲染为空、不能伪装成 0**（否则污染看板排序） |
| 3 | `sanitizeFilenamePreserveEmoji` | emoji 保留、非法字符替换、按码点截断不切坏 emoji |
| 4 | `extractAllXHSURLs` | 长链/短链/混合、批内去重、非小红书域名忽略、空文本 |
| 5 | `normalizeContentLines` | tab 与**不可见字符**（U+200B / U+3164）伪空行、行尾清理、连续空行压缩；**行内不可见字符必须保留**（emoji 的 ZWJ 序列、作者有意隔词） |
| 6 | frontmatter 渲染 | 中文键输出为合法 YAML、缺失值空键、**英文键不得残留**（`type`/`aliases`/`tags` 除外） |

另有两条**守门断言**：

- 每个占位符都必须在设置页说明表里有条目 → **新增占位符却忘写说明，测试直接失败**
- 「中文占位符不被替换」—— 把 ASCII-only 限制钉住，谁放宽正则谁就会看到这条失败

以及一段**可选**的库内配置对照：若本机存在 `E:/第二大脑/.obsidian/plugins/xhs-importer-pro/data.json`，
会打印实际字段并检查中文化是否到位；换机器无此路径时自动跳过。

## probe.mjs —— 页面字段探测

```bash
node dev/probe.mjs <分享链接> [更多链接...]
```

抓笔记页并打印 `__INITIAL_STATE__` 里的**全部字段**，用来确认无登录状态下到底能拿到什么。
链接通过命令行传入（早期版本把测试链接写死在脚本里，token 会过期，已改掉）。

**当前实测结论**：

| 拿得到 | 拿不到 |
|---|---|
| 标题 / 正文 / 图片（可下载）/ 视频直链 / 发布时间 / IP 属地 / 作者昵称与 userId / 点赞·收藏·评论·分享数 / 话题标签 | **评论区内容**（需登录） |

⚠️ **必须用「分享链接」** —— App 里「分享 → 复制链接」，或网页版的分享按钮。
浏览器地址栏复制的 `explore/<id>?xsec_token=...` 里，token **绑定登录会话**，裸请求必被拦（302 → 登录页）。
