# xhs-importer-pro 1.0.13

> 本版相对 1.0.12：字段名全部中文化、设置页可读化，并修掉 3 个真实使用中发现的 bug。

## 新增

- **设置页的占位符列表改为逐条中文说明** —— 原先只是三行 `{{...}}` 堆砌，看不出 `{{collectedCount}}` 是"收藏数"。现在每个占位符单独一行并附说明。
- 加一句澄清：**字段名**（写进笔记顶部的属性名）vs **占位符**（只在字段的「默认值」里用、不会出现在笔记中）。

## 变更

- **frontmatter 字段名全部中文化**：`created`→`创建日期`、`published`→`发布日期`、`author`→`博主`、`source`→`笔记链接`。
  最终 12 个键：`type / aliases / 创建日期 / 发布日期 / 博主 / 笔记链接 / 点赞 / 收藏 / 评论 / 转发 / tags / 上级概念`
  —— 仅 `type`（Bases 过滤锚点）与 `aliases` / `tags`（Obsidian 内置属性）保留英文，三者都是技术必需。
- 「笔记链接」移到「博主」之后，与配套知识库的卡片字段顺序一致。

## 修复

- **`创建日期` 差一天**：原先取 UTC 日期，东八区 00:00–08:00 之间导入会被写成**前一天**（实测：09-19 00:43 导入写成 2026-09-18）。现在与「发布日期」共用同一套本地日期逻辑，不再两套口径。
- **单条导入不走去重索引**：原先只有批量导入读写索引，单条导入既无去重保护（重复导入会静默生成 `标题-1.md` 副本），批量导入也认不出它。现在两条路径完全一致：读索引 → 校验笔记是否仍在仓库 → 写回。
- **正文残留"看不见的空行"**：零宽空格（U+200B）、零宽连接符（U+200C/D）与韩文填充符（U+3164，即 `ㅤ`）**不属 `\s`**，原判定看不出来。现在四种变体统一归一为真空行；**行内的不可见字符保持不动**（作者有意用来隔词）。

## 使用提示

- **重导同一篇前先删掉已导入的笔记**，否则会被判为重复并跳过 —— 判定依据是"笔记是否仍在仓库里"，删掉即可重新导入。
- 从 1.0.12 升上来时，**已有笔记里的旧英文键不会自动改名**，只有新导入的笔记使用中文键。

## 测试

`dev/verify.mjs` **43 项断言全部通过**，含时区回归测试（本地构造 `00:43`，任何机器上退回 UTC 实现即失败）、四种伪空行的断言、以及"新增占位符却忘记写设置页说明即失败"的守门断言。
